# UseCase: AddManualNote — Добавить заметку вручную в ленту событий

## Что решает

Позволяет пользователю добавить произвольную текстовую заметку в ленту событий лида. В отличие от автоматических событий, эта заметка вводится вручную — для фиксации звонков, встреч или любой другой информации не в формате комментария.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Пользователь с доступом к лиду |
| **Роли** | `consultant` (только свои), `sales_manager`, `director`, `admin` |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `lead_id` | `UUID` | ID лида |
| `text` | `str` | Текст заметки |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить лид, проверить доступ
3. Создать LeadTimelineEvent(event_type="manual_note", actor_id=actor.id, payload={text})
4. Сохранить в БД
5. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `LeadNotFoundError` | Лид не найден |
| `LeadAccessDeniedError` | Нет доступа |

---

## Результат

`None` — успешное выполнение.

---

## Бизнес-правила

- Ручная заметка — **иммутабельна** после создания (как все события timeline)
- Отличие от комментария: комментарий можно редактировать 15 минут, заметку — нельзя никогда
- Используется для логирования действий вне системы: "позвонил, договорился на встречу"
