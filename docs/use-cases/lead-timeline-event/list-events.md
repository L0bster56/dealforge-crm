# UseCase: ListLeadTimelineEvents — Список событий лида

## Что решает

Возвращает хронологическую ленту всех событий по лиду. Лента формируется **автоматически** при выполнении других use cases (создание, обновление, перемещение, задачи, комментарии и т.д.). События иммутабельны — их нельзя изменить или удалить.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Пользователь с доступом к лиду |
| **Роли** | Все роли (с ограничениями) |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `lead_id` | `UUID` | ID лида |
| `page` | `int` | Страница |
| `size` | `int` | Размер страницы |

---

## Типы событий в ленте

| Тип события | Когда создаётся |
|-------------|-----------------|
| `lead_created` | При `CreateLead` |
| `lead_updated` | При `UpdateLead` |
| `stage_changed` | При `MoveLead` |
| `assigned` | При `AssignLead` |
| `lead_archived` | При `ArchiveLead` |
| `lead_restored` | При `ArchiveLead` (разархивирование) |
| `task_created` | При `CreateTask` |
| `task_completed` | При `CompleteTask` |
| `comment_added` | При `CreateLeadComment` |
| `manual_note` | При `AddManualNote` (ручная заметка) |

---

## Порядок действий

```
1. Загрузить лид, проверить доступ
2. Загрузить события из БД, отсортированные по created_at DESC
3. Вернуть PageResult[TimelineEventViewDTO]
```

---

## Результат (`TimelineEventViewDTO`)

| Поле | Тип |
|------|-----|
| `id` | `UUID` |
| `event_type` | `str` |
| `actor_id` | `UUID` |
| `actor_name` | `str` |
| `payload` | `dict` (детали события) |
| `created_at` | `datetime` |

---

## Бизнес-правила

- События **иммутабельны** — нельзя редактировать или удалять
- `payload` содержит контекст события (например, для `stage_changed`: `from_stage_name`, `to_stage_name`)
- События создаются **автоматически внутри других use cases** — не требуют вызова отдельного use case
