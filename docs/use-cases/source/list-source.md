# UseCase: ListSource — Список источников лидов

## Что решает

Возвращает постраничный список источников лидов с поддержкой фильтрации. Используется в разделе настроек CRM для просмотра всех каналов поступления лидов.

**Файл:** `backend/src/backend/application/source/use_cases/list_source.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Любой авторизованный пользователь |
| **Роли** | Все роли |

---

## Входные данные (`ListSourceCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `page` | `int` | Номер страницы |
| `size` | `int` | Размер страницы |
| `source_type` | `SourceType \| None` | Фильтр по типу источника |
| `is_active` | `bool \| None` | Фильтр по статусу активности |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить список источников через uow.sources.list(cmd)
   (репозиторий применяет фильтры и пагинацию)
3. Конвертировать каждый источник в view через to_result(source)
4. Вернуть PageResult[GetSourceResult]
```

---

## Возможные ошибки

Нет специфических ошибок.

---

## Результат (`PageResult[GetSourceResult]`)

| Поле | Тип |
|------|-----|
| `items` | `list[GetSourceResult]` |
| `page` | `int` |
| `size` | `int` |
| `total_items` | `int` |

---

## Бизнес-правила

- По умолчанию удалённые источники (`is_deleted = True`) **не включаются** в список
- `secret_hash` не возвращается ни для одного источника
