# UseCase: DeleteSource — Удалить источник лидов (soft delete)

## Что решает

Выполняет мягкое удаление источника лидов — устанавливает `is_deleted = True` и `is_active = False`. Источник перестаёт принимать новые лиды, но история лидов из этого источника сохраняется.

**Файл:** `backend/src/backend/application/source/use_cases/delete_source.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Менеджер или выше |
| **Роли** | `sales_manager`, `director`, `admin` |

---

## Входные данные

Источник передаётся как атрибут use case (`self.source`). Дополнительных параметров нет.

---

## Порядок действий

```
1. Проверить права актора через CanManageSourcesPolicy
   └─ Если нет прав → ошибка PermissionError

2. Открыть Unit of Work

3. Вызвать source.delete()
   └─ Устанавливает is_deleted = True, is_active = False

4. Сохранить изменения через uow.sources.update(self.source)

5. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `PermissionError` | Нет прав |

---

## Результат

`None` — успешное выполнение без возвращаемого значения.

---

## Бизнес-правила

- Удаление **мягкое** — данные сохраняются в БД
- После удаления webhook-источник **перестаёт принимать входящие запросы** (проверяется `is_active` перед обработкой)
- Лиды, ранее созданные через этот источник, сохраняют ссылку на `source_id` — аналитика по источникам корректна
