# UseCase: ActivateSource — Активировать источник лидов

## Что решает

Включает источник лидов — устанавливает `is_active = True`. После активации источник начинает принимать новые лиды (webhook обрабатывает входящие запросы, публичная форма становится доступной).

**Файл:** `backend/src/backend/application/source/use_cases/activate_source.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Менеджер или выше |
| **Роли** | `sales_manager`, `director`, `admin` |

---

## Входные данные

Источник передаётся как атрибут use case (`self.source`). Дополнительных параметров нет.

---

## Порядок действий

```
1. Проверить права актора через CanManageSourcesPolicy
   └─ Если нет прав → ошибка PermissionError

2. Открыть Unit of Work

3. Вызвать source.activate()
   └─ Устанавливает is_active = True

4. Сохранить изменения через uow.sources.update(self.source)

5. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `PermissionError` | Нет прав |

---

## Результат

`None` — успешное выполнение без возвращаемого значения.

---

## Бизнес-правила

- Удалённый источник (`is_deleted = True`) **не должен** активироваться — проверка на уровне роутера (загрузить источник через `GetSource` — он вернёт ошибку для удалённых)
- После активации источник сразу начинает работать без перезапуска сервисов
