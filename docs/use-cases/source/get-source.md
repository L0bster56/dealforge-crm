# UseCase: GetSource — Получить источник лидов

## Что решает

Возвращает данные конкретного источника лидов по его UUID. Конвертирует доменную сущность в view-DTO, адаптированный для ответа API.

**Файл:** `backend/src/backend/application/source/use_cases/get_source.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Любой авторизованный пользователь |
| **Роли** | Все роли |

---

## Входные данные (`GetSourceCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `source_id` | `UUID` | ID источника |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить источник из БД по source_id
3. Если источник не найден ИЛИ is_deleted = True → ошибка SourceNotFoundError
4. Конвертировать в view через to_result(source)
5. Вернуть GetSourceResult
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `SourceNotFoundError` | Источник не найден или удалён (`is_deleted = True`) |

---

## Результат (`GetSourceResult`)

View-DTO источника. Содержимое зависит от типа:
- Для webhook: конфигурация без `secret_hash` (токен не раскрывается)
- Для public_form: конфигурация с публичным URL
- Для manual: без конфигурации

---

## Бизнес-правила

- `secret_hash` для webhook **никогда не возвращается** клиенту — только при создании через `CreateSource` или пересоздании через `RegenerateWebhookSecret`
- Удалённые источники (`is_deleted = True`) возвращают ошибку "не найден" — без раскрытия причины
