# UseCase: DeactivateSource — Деактивировать источник лидов

## Что решает

Временно отключает источник лидов — устанавливает `is_active = False`. Источник перестаёт принимать новые лиды, но не удаляется. Используется для временной паузы (например, во время технических работ или перенастройки).

**Файл:** `backend/src/backend/application/source/use_cases/deactivate_cource.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Менеджер или выше |
| **Роли** | `sales_manager`, `director`, `admin` |

---

## Входные данные

Источник передаётся как атрибут use case (`self.source`). Дополнительных параметров нет.

---

## Порядок действий

```
1. Проверить права актора через CanManageSourcesPolicy
   └─ Если нет прав → ошибка PermissionError

2. Открыть Unit of Work

3. Вызвать source.deactivate()
   └─ Устанавливает is_active = False

4. Сохранить изменения через uow.sources.update(self.source)

5. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `PermissionError` | Нет прав |

---

## Результат

`None` — успешное выполнение без возвращаемого значения.

---

## Бизнес-правила

- Деактивация **обратима** — источник можно повторно активировать через `ActivateSource`
- В отличие от `DeleteSource`, деактивация **не устанавливает `is_deleted = True`**
- Лиды, уже созданные через этот источник, не затрагиваются
