# UseCase: ListTask — Список задач

## Что решает

Возвращает список задач. Поддерживает два режима: задачи конкретного лида (вкладка в карточке лида) и все задачи текущего пользователя (страница "Мои задачи").

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Любой авторизованный пользователь |
| **Роли** | Все роли |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `lead_id` | `UUID \| None` | Задачи конкретного лида |
| `assigned_to` | `UUID \| None` | Задачи конкретного менеджера |
| `status` | `TaskStatus \| None` | Фильтр по статусу |
| `due_before` | `datetime \| None` | Дедлайн до |
| `page` | `int` | Страница |
| `size` | `int` | Размер страницы |

---

## Порядок действий

```
1. Применить ролевой фильтр:
   - Consultant → принудительно assigned_to = actor.id (только свои задачи)

2. Открыть Unit of Work

3. Загрузить задачи через репозиторий с фильтрами

4. Вернуть PageResult[TaskViewDTO]
```

---

## Бизнес-правила

- **Consultant** видит только задачи, назначенные ему
- Просроченные задачи (`due_date < now() AND status != done`) отмечаются как `overdue`
- Удалённые задачи (`is_deleted = True`) не отображаются
