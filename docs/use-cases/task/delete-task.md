# UseCase: DeleteTask — Удалить задачу

## Что решает

Мягко удаляет задачу (`is_deleted = True`). Задача исчезает из всех списков. Используется для отмены ошибочно созданных задач.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Создатель задачи или менеджер |
| **Роли** | `sales_manager`, `director`, `admin` (Consultant — только свои задачи) |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `task_id` | `UUID` | ID задачи |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить задачу, проверить права
3. Вызвать task.delete() → is_deleted = True
4. Сохранить в БД
5. Зафиксировать транзакцию (commit)
```

---

## Бизнес-правила

- Удалённые задачи **не восстанавливаются** через стандартный UI
- Завершённые задачи (`status = done`) также могут быть удалены
