# UseCase: CreateTask — Создать задачу

## Что решает

Создаёт задачу, привязанную к лиду. Задача — это конкретное действие, которое нужно выполнить по лиду (позвонить, отправить КП, провести встречу). Имеет дедлайн и может быть назначена другому пользователю.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Пользователь с доступом к лиду |
| **Роли** | `consultant` (только свои лиды), `sales_manager`, `director`, `admin` |

---

## Входные данные

| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|
| `lead_id` | `UUID` | ✅ | Лид, к которому привязана задача |
| `title` | `str` | ✅ | Название задачи |
| `description` | `str \| None` | — | Описание |
| `due_date` | `datetime \| None` | — | Дедлайн |
| `assigned_to` | `UUID \| None` | — | Исполнитель (по умолчанию — создатель) |
| `task_type` | `TaskType` | ✅ | Тип: `call / meeting / email / other` |

---

## Порядок действий

```
1. Открыть Unit of Work

2. Загрузить лид по lead_id, проверить доступ
   └─ Consultant → только свои лиды

3. Если assigned_to передан:
   - Проверить, что пользователь активен

4. Создать Task.create(...)
   └─ status = pending
   └─ created_by = actor.id
   └─ is_deleted = False

5. Сохранить задачу в БД

6. Создать LeadTimelineEvent "task_created"

7. Если due_date задан → запланировать уведомление исполнителю за N часов до дедлайна

8. Зафиксировать транзакцию (commit)

9. Вернуть CreateTaskResult(task_id=task.id)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `LeadNotFoundError` | Лид не найден |
| `LeadAccessDeniedError` | Нет доступа к лиду |
| `UserNotFoundError` | Назначаемый пользователь не найден |

---

## Результат

| Поле | Тип |
|------|-----|
| `task_id` | `UUID` |

---

## Бизнес-правила

- Если `assigned_to` не указан — задача назначается создателю
- Задача привязана к **одному** лиду (нет standalone-задач)
- Страница "Мои задачи" показывает все задачи, где `assigned_to = actor.id` — независимо от доступа к лиду
