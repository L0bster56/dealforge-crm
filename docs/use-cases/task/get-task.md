# UseCase: GetTask — Получить задачу

## Что решает

Возвращает полные данные задачи по UUID. Проверяет доступ к лиду, к которому привязана задача.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Любой авторизованный пользователь |
| **Роли** | Все роли (с ограничениями) |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `task_id` | `UUID` | ID задачи |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить задачу по task_id
   └─ Если не найдена → TaskNotFoundError
3. Проверить доступ к родительскому лиду:
   - Consultant → только если lead.assigned_to == actor.id
4. Вернуть TaskViewDTO
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `TaskNotFoundError` | Задача не найдена |
| `TaskAccessDeniedError` | Нет доступа |
