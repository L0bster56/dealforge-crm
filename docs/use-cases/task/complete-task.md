# UseCase: CompleteTask — Завершить задачу

## Что решает

Переводит задачу в статус `done`. Фиксирует время выполнения. Создаёт событие в timeline лида.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Исполнитель задачи или менеджер |
| **Роли** | `consultant` (только свои задачи), `sales_manager`, `director`, `admin` |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `task_id` | `UUID` | ID задачи |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить задачу, проверить доступ
3. Если задача уже done → ошибка TaskAlreadyCompletedError
4. Вызвать task.complete() → status = done, completed_at = now()
5. Сохранить в БД
6. Создать LeadTimelineEvent "task_completed"
7. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `TaskAlreadyCompletedError` | Задача уже выполнена |
| `TaskAccessDeniedError` | Нет прав |

---

## Результат

`None` — успешное выполнение.
