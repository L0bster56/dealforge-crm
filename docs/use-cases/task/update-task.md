# UseCase: UpdateTask — Обновить задачу

## Что решает

Обновляет данные задачи: название, описание, дедлайн, исполнителя. Смена статуса выполняется через `CompleteTask` для явного разграничения.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Создатель задачи или менеджер |
| **Роли** | `consultant` (только свои задачи), `sales_manager`, `director`, `admin` |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `task_id` | `UUID` | ID задачи |
| `title` | `str \| None` | Новое название |
| `description` | `str \| None` | Новое описание |
| `due_date` | `datetime \| None` | Новый дедлайн |
| `assigned_to` | `UUID \| None` | Новый исполнитель |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить задачу, проверить доступ
3. Применить изменения через доменные методы (patch-семантика)
4. Сохранить в БД
5. Создать LeadTimelineEvent "task_updated"
6. Зафиксировать транзакцию (commit)
```

---

## Бизнес-правила

- Завершённые задачи (`status = done`) **нельзя редактировать** — только просматривать
- Изменение дедлайна обновляет запланированное уведомление
