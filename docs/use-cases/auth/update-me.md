# UseCase: UpdateMe — Обновить профиль текущего пользователя

## Что решает

Позволяет авторизованному пользователю изменить собственные данные: имя, фамилию и email. Username (логин) через этот use case не меняется. Роль и статус активности изменить через этот use case невозможно — только через `UpdateUser` (только Admin).

**Файл:** `backend/src/backend/application/auth/use_cases/update_me.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Текущий авторизованный пользователь (self) |
| **Роли** | Все роли |

---

## Входные данные (`UpdateMeCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `first_name` | `str` | Новое имя |
| `last_name` | `str` | Новая фамилия |
| `email` | `EmailStr` | Новый email |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Проверить, не занят ли новый email другим пользователем
   (исключая текущего пользователя из проверки)
   └─ Если email занят → ошибка EmailAlreadyExistsError
3. Вызвать user.change_first_name(cmd.first_name)
   └─ Валидация через Value Object Name (не пустое, max 255 симв.)
4. Вызвать user.change_last_name(cmd.last_name)
   └─ Валидация через Value Object Name
5. Вызвать user.change_email(str(cmd.email))
   └─ Валидация через Value Object Email
6. Сохранить изменения в БД
7. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `EmailAlreadyExistsError` | Указанный email уже используется другим пользователем |
| `ValueError` (VO) | Имя/фамилия пустые или превышают 255 символов |
| `ValueError` (VO) | Некорректный формат email |

---

## Результат

`None` — успешное выполнение без возвращаемого значения.

---

## Бизнес-правила

- Пользователь может изменить только **свои** данные — use case принимает `user: User` (текущий пользователь) через dependency injection
- **Username нельзя изменить** через этот use case (для смены логина нужен отдельный механизм или только Admin через `UpdateUser`)
- Email проверяется на уникальность среди всех пользователей, **кроме самого себя** — иначе нельзя было бы "сохранить без изменений"
