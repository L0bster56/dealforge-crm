# UseCase: GetMe — Получить текущего пользователя

## Что решает

Возвращает полные данные авторизованного пользователя по его access-токену. Используется фронтендом при загрузке приложения для получения профиля и роли текущего пользователя.

**Файл:** `backend/src/backend/application/auth/use_cases/get_me.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Любой авторизованный пользователь |
| **Роли** | Все роли |

---

## Входные данные (`GetMeCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `token` | `str` | Действующий JWT access-токен |

---

## Порядок действий

```
1. Декодировать access_token через TokenService
   └─ Если токен невалиден или истёк → ошибка на уровне TokenService
2. Извлечь user_id из payload токена
3. Открыть Unit of Work
4. Загрузить пользователя из БД по user_id
5. Если пользователь не найден → ошибка InActiveUserError
6. Вернуть доменную сущность User
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| JWT decode error | Токен истёк или имеет неверную подпись |
| `InActiveUserError` | Пользователь не найден в БД |

---

## Результат

Доменная сущность `User` со всеми полями:

| Поле | Тип |
|------|-----|
| `id` | `UUID` |
| `first_name` | `Name` |
| `last_name` | `Name` |
| `username` | `Username` |
| `email` | `Email` |
| `role` | `UserRole` |
| `is_active` | `bool` |
| `last_interaction` | `datetime \| None` |

---

## Бизнес-правила

- Используется как dependency-инъекция в роутерах FastAPI — вызывается перед каждым защищённым эндпоинтом для получения `current_user`
- Не проверяет `is_active` отдельно — если пользователь удалён из БД, он не будет найден
