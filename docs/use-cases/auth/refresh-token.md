# UseCase: RefreshToken — Обновление токенов

## Что решает

Выдаёт новую пару JWT-токенов по действующему refresh-токену. Позволяет клиенту оставаться авторизованным без повторного ввода пароля — access-токен имеет короткое время жизни (15 мин), а refresh-токен — длинное (30 дней).

**Файл:** `backend/src/backend/application/auth/use_cases/refresh_token.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Любой пользователь с действующим refresh-токеном |
| **Роли** | Все роли |

---

## Входные данные (`RefreshTokenCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `refresh_token` | `str` | Действующий JWT refresh-токен |

---

## Порядок действий

```
1. Декодировать refresh_token через TokenService
   └─ Если токен истёк или невалиден → ошибка на уровне TokenService (JWT decode error)
2. Извлечь user_id из payload токена
3. Открыть Unit of Work
4. Загрузить пользователя из БД по user_id
5. Проверить флаг is_active пользователя
   └─ Если is_active = false → ошибка InActiveUserError
6. Сгенерировать новый access_token (JWT, TTL = 15 мин)
7. Сгенерировать новый refresh_token (JWT, TTL = 30 дней)
8. Вернуть RefreshTokenResult
```

> Транзакция (commit) не выполняется — use case только читает пользователя, запись в БД не производится.

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| JWT decode error | Токен истёк, подпись неверна или формат некорректен |
| `InActiveUserError` | Пользователь был деактивирован после выдачи токена |

---

## Результат (`RefreshTokenResult`)

| Поле | Тип | Описание |
|------|-----|----------|
| `access_token` | `str` | Новый JWT access-токен (15 мин) |
| `refresh_token` | `str` | Новый JWT refresh-токен (30 дней) |
| `token_type` | `str` | Тип токена (`"bearer"`) |

---

## Бизнес-правила

- Оба токена выдаются заново (rotation) — старый refresh-токен становится невалидным после использования нового
- Если пользователь деактивирован администратором, даже действующий refresh-токен не позволит войти
