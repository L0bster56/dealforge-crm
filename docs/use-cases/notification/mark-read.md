# UseCase: MarkNotificationRead — Прочитать уведомление

## Что решает

Отмечает конкретное уведомление как прочитанное (`is_read = True`). Используется при клике на уведомление в интерфейсе.

**Статус:** ❌ Не реализовано (планируется — Приоритет 3)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Владелец уведомления |
| **Роли** | Все роли |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `notification_id` | `UUID` | ID уведомления |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить уведомление по notification_id
   └─ Если не найдено → NotificationNotFoundError
3. Проверить, что notification.user_id == actor.id
   └─ Если нет → NotificationAccessDeniedError
4. Вызвать notification.mark_read() → is_read = True, read_at = now()
5. Сохранить в БД
6. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `NotificationNotFoundError` | Уведомление не найдено |
| `NotificationAccessDeniedError` | Уведомление принадлежит другому пользователю |

---

## Результат

`None` — успешное выполнение.
