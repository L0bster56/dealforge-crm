# UseCase: MarkAllNotificationsRead — Прочитать все уведомления

## Что решает

Отмечает все непрочитанные уведомления текущего пользователя как прочитанные за один запрос. Используется при нажатии "Прочитать всё" в панели уведомлений.

**Статус:** ❌ Не реализовано (планируется — Приоритет 3)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Текущий авторизованный пользователь |
| **Роли** | Все роли |

---

## Входные данные

Дополнительных параметров нет — операция применяется ко всем непрочитанным уведомлениям актора.

---

## Порядок действий

```
1. Открыть Unit of Work
2. Выполнить bulk-update:
   UPDATE notifications
   SET is_read = True, read_at = now()
   WHERE user_id = actor.id AND is_read = False
3. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

Нет специфических ошибок.

---

## Результат

`None` — успешное выполнение.

---

## Бизнес-правила

- Операция применяется **только** к уведомлениям текущего пользователя
- Реализуется через один SQL-запрос (bulk update) — без загрузки всех объектов в память
