# UseCase: MoveLead — Переместить лид в другой этап воронки

## Что решает

Перемещает лид из одного этапа в другой в рамках той же воронки. Это ключевое действие в работе с Kanban-доской — drag-and-drop лида между колонками. Автоматически фиксирует событие в timeline.

**Статус:** ❌ Не реализовано (планируется — Приоритет 1)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Пользователь с доступом к лиду |
| **Роли** | `consultant` (только свои), `sales_manager`, `director`, `admin` |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `lead_id` | `UUID` | ID лида |
| `stage_id` | `UUID` | ID нового этапа |

---

## Порядок действий

```
1. Открыть Unit of Work

2. Загрузить лид из БД
   └─ Если не найден → LeadNotFoundError

3. Проверить доступ по роли (consultant → только свои)

4. Загрузить новый этап из БД
   └─ Если не найден → StageNotFoundError

5. Проверить, что этап принадлежит той же воронке, что и лид:
   stage.funnel_id == lead.funnel_id
   └─ Если нет → StageNotFunnelError

6. Сохранить предыдущий stage_id для записи события

7. Вызвать lead.move_to_stage(stage_id)
   └─ Обновляет stage_id

8. Сохранить лид в БД

9. Создать LeadTimelineEvent "stage_changed" с from_stage и to_stage (автоматически)

10. Если новый этап имеет kind = won → записать дату закрытия (won_at)
    Если новый этап имеет kind = lost → записать дату закрытия (lost_at)

11. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `LeadNotFoundError` | Лид не найден |
| `StageNotFoundError` | Этап не найден |
| `StageNotFunnelError` | Этап не принадлежит воронке лида |
| `LeadAccessDeniedError` | Нет прав на перемещение |

---

## Результат

`None` — успешное выполнение.

---

## Бизнес-правила

- Лид можно перемещать **только внутри своей воронки** — смена воронки не поддерживается (по PRD: лид находится в одной воронке одновременно)
- При попадании в этап `won` или `lost` — автоматически обновляется статус лида
- Каждое перемещение фиксируется в `LeadTimelineEvent` — полная история движения лида по воронке
- Перемещение в архивированный этап (`is_archived = True`) — запрещено или требует подтверждения
