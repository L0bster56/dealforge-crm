# UseCase: SetCustomValue — Задать / обновить значение кастомного поля лида

## Что решает

Устанавливает или обновляет значение кастомного поля для конкретного лида. Если значение для данного поля уже существует — перезаписывает его. Если значение передано как `null` / пустое — удаляет его.

**Статус:** ❌ Не реализовано (планируется — Приоритет 1)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Пользователь с доступом к лиду |
| **Роли** | `consultant` (только свои), `sales_manager`, `director`, `admin` |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `lead_id` | `UUID` | ID лида |
| `custom_field_id` | `UUID` | ID кастомного поля |
| `value` | `FieldValue \| None` | Значение (тип зависит от `field_type`). `None` — удалить значение |

---

## Порядок действий

```
1. Открыть Unit of Work

2. Загрузить лид из БД
   └─ Если не найден → LeadNotFoundError

3. Проверить доступ по роли (consultant → только свои)

4. Загрузить кастомное поле по custom_field_id
   └─ Если не найдено или is_deleted = True → CustomFieldNotFoundError

5. Валидировать значение по типу поля:
   - text: строка
   - number: число
   - date: дата
   - boolean: true/false
   - select_one: значение должно быть в списке enums
   - select_all: все значения должны быть в списке enums
   └─ Если тип не совпадает → FieldTypeValidationError

6. Если value = None → вызвать lead.remove_custom_value(custom_field_id)
   Иначе → вызвать lead.set_custom_value(custom_field, value)

7. Сохранить лид в БД

8. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `LeadNotFoundError` | Лид не найден |
| `CustomFieldNotFoundError` | Кастомное поле не найдено или удалено |
| `FieldTypeValidationError` | Значение не соответствует типу поля |
| `LeadAccessDeniedError` | Нет доступа к лиду |

---

## Результат

`None` — успешное выполнение.

---

## Бизнес-правила

- **Upsert-семантика**: если значение уже есть — обновляется, нет — создаётся
- Значения для `select_one` и `select_all` проверяются по списку актуальных enum-вариантов
- Удалённые кастомные поля (`is_deleted = True`) не принимают новых значений
