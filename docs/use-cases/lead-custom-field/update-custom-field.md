# UseCase: UpdateCustomField — Переименовать кастомное поле

## Что решает

Изменяет название существующего кастомного поля лида. Тип поля (`field_type`) изменить нельзя — это сломало бы значения, уже сохранённые в лидах.

**Файл:** `backend/src/backend/application/lead/use_cases/custom_fields/update_custom_field.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Менеджер или выше |
| **Роли** | `sales_manager`, `director`, `admin` |

---

## Входные данные (`UpdateCustomFieldCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | `str` | Новое название поля |

Поле передаётся как атрибут use case (`self.field`).

---

## Порядок действий

```
1. Проверить права актора через CanMangeCustomField
   └─ Если нет прав → ошибка PermissionError

2. Открыть Unit of Work

3. Вызвать field.rename(cmd.name)
   └─ Валидация через Value Object LeadName

4. Сохранить через uow.custom_fields.update(self.field)

5. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `PermissionError` | Роль актора — `consultant` |
| `ValueError` (VO) | Некорректное название |

---

## Результат

`None` — успешное выполнение без возвращаемого значения.

---

## Бизнес-правила

- Уникальность нового имени **не проверяется** в текущей реализации
- Тип поля (`field_type`) **нельзя изменить** — это принципиальное ограничение для сохранения целостности данных
