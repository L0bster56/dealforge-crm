# UseCase: RestoreCustomField — Восстановить удалённое кастомное поле

## Что решает

Восстанавливает мягко удалённое кастомное поле — устанавливает `is_deleted = False`. Поле снова появляется в интерфейсе, и его можно использовать для заполнения лидов.

**Файл:** `backend/src/backend/application/lead/use_cases/custom_fields/restore_custom_field.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Менеджер или выше |
| **Роли** | `sales_manager`, `director`, `admin` |

---

## Входные данные

Поле передаётся как атрибут use case (`self.field`). Дополнительных параметров нет.

> Чтобы получить удалённое поле, нужно вызвать `GetCustomField` с `include_deleted = True`.

---

## Порядок действий

```
1. Проверить права актора через CanMangeCustomField
   └─ Если нет прав → ошибка PermissionError

2. Открыть Unit of Work

3. Вызвать field.restore()
   └─ Устанавливает is_deleted = False

4. Сохранить через uow.custom_fields.update(field=self.field)

5. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Поле | Условие |
|------|---------|
| `PermissionError` | Нет прав |

---

## Результат

`None` — успешное выполнение без возвращаемого значения.

---

## Бизнес-правила

- После восстановления все **ранее сохранённые значения** в лидах снова корректно отображаются
- Восстановление возможно в любой момент — нет ограничения по времени
