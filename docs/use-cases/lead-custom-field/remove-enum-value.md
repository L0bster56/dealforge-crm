# UseCase: RemoveEnumValue — Удалить вариант выбора из кастомного поля

## Что решает

Удаляет вариант выбора (`enum`) из кастомного поля. Перед удалением проверяет, что этот вариант **не используется** ни в одном лиде — защита от потери данных.

**Файл:** `backend/src/backend/application/lead/use_cases/custom_fields/remove_enum_value.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Менеджер или выше |
| **Роли** | `sales_manager`, `director`, `admin` |

---

## Входные данные (`RemoveEnumValueCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `enum_id` | `UUID` | ID варианта выбора для удаления |

Поле передаётся как атрибут use case (`self.custom_field`).

---

## Порядок действий

```
1. Проверить права актора через CanMangeCustomField
   └─ Если нет прав → ошибка PermissionError

2. Открыть Unit of Work

3. Подсчитать, сколько лидов используют данный enum:
   uow.custom_fields.count_values_with_enum_values(cmd.enum_id)
   └─ Если usage_count > 0 → ошибка EnumInUseError

4. Вызвать custom_field.remove(cmd.enum_id)
   └─ Фильтрует список enums, исключая удаляемый

5. Сохранить через uow.custom_fields.update(self.custom_field)

6. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `PermissionError` | Нет прав |
| `EnumInUseError` | Вариант используется хотя бы в одном лиде |

---

## Результат

`None` — успешное выполнение без возвращаемого значения.

---

## Бизнес-правила

- **Нельзя удалить вариант, если он используется** — это гарантирует целостность данных лидов
- Для удаления используемого варианта нужно сначала вручную сменить значение во всех лидах
- Это **физическое** удаление enum — восстановить его нельзя (нужно добавить заново через `AddEnumValue`)
