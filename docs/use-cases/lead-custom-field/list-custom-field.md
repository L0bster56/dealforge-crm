# UseCase: ListCustomField — Список кастомных полей

## Что решает

Возвращает список всех кастомных полей лидов. Поддерживает фильтрацию по типу поля и включение удалённых полей. Используется для настройки формы лида и при конфигурации публичной формы источника.

**Файл:** `backend/src/backend/application/lead/use_cases/custom_fields/list_custom_field.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Любой авторизованный пользователь |
| **Роли** | Все роли |

---

## Входные данные (`ListCustomFieldCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `field_type` | `FieldType \| None` | Фильтр по типу поля (опционально) |
| `include_deleted` | `bool` | Включать ли удалённые поля |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить поля через uow.custom_fields.list_all(field_type, include_deleted)
   (репозиторий применяет фильтры)
3. Конвертировать каждое поле в view-DTO через to_view(field)
4. Вернуть list[CustomFieldViewDTO]
```

---

## Возможные ошибки

Нет специфических ошибок.

---

## Результат

`list[CustomFieldViewDTO]` — список кастомных полей (без пагинации, т.к. полей обычно немного).
