# UseCase: DeleteLeadComment — Удалить комментарий

## Что решает

Мягко удаляет комментарий (`is_deleted = True`). Автор может удалить свой комментарий в любое время. Менеджер может удалить любой комментарий.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Автор комментария или менеджер+ |
| **Роли** | Автор (любая роль) или `sales_manager`, `director`, `admin` |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `comment_id` | `UUID` | ID комментария |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить комментарий по comment_id
   └─ Если не найден → CommentNotFoundError
3. Проверить права:
   - Автор → может удалять свой
   - sales_manager+ → может удалять любой
   └─ Если нет прав → CommentDeleteDeniedError
4. Вызвать comment.delete() → is_deleted = True
5. Сохранить в БД
6. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `CommentNotFoundError` | Комментарий не найден |
| `CommentDeleteDeniedError` | Нет прав |

---

## Результат

`None` — успешное выполнение.

---

## Бизнес-правила

- Мягкое удаление — в ленте комментариев отображается как "(комментарий удалён)"
- **Consultant** может удалять только свои комментарии, **sales_manager+** — любые
