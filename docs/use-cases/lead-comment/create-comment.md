# UseCase: CreateLeadComment — Добавить комментарий к лиду

## Что решает

Добавляет текстовый комментарий к лиду. Комментарии используются для фиксации переговоров, договорённостей и внутренних заметок команды. Отображаются в хронологическом порядке в карточке лида.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Пользователь с доступом к лиду |
| **Роли** | `consultant` (только свои лиды), `sales_manager`, `director`, `admin` |

---

## Входные данные

| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|
| `lead_id` | `UUID` | ✅ | ID лида |
| `text` | `str` | ✅ | Текст комментария (max 5000 символов) |

---

## Порядок действий

```
1. Открыть Unit of Work

2. Загрузить лид по lead_id, проверить доступ
   └─ Consultant → только свои лиды
   └─ Если лид удалён/не найден → LeadNotFoundError

3. Создать LeadComment.create(lead_id, text, author_id=actor.id)
   └─ Генерируется UUID
   └─ created_at = now()
   └─ is_deleted = False

4. Сохранить комментарий в БД

5. Создать LeadTimelineEvent "comment_added" (автоматически)

6. Зафиксировать транзакцию (commit)

7. Вернуть CreateCommentResult(comment_id=comment.id)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `LeadNotFoundError` | Лид не найден или недоступен |
| `ValueError` | Текст пустой или превышает 5000 символов |

---

## Результат

| Поле | Тип |
|------|-----|
| `comment_id` | `UUID` |

---

## Бизнес-правила

- Комментарий привязан к конкретному **автору** (`author_id`) — нельзя редактировать чужие комментарии
- Редактирование доступно в течение **15 минут** после создания (окно редактирования по PRD)
- Комментарий к удалённому лиду добавить нельзя
