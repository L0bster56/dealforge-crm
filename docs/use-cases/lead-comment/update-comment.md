# UseCase: UpdateLeadComment — Редактировать комментарий

## Что решает

Позволяет автору отредактировать свой комментарий. Доступно только в течение **15 минут** после создания — после этого окна комментарий становится неизменным.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Автор комментария |
| **Роли** | Только автор (любая роль) |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `comment_id` | `UUID` | ID комментария |
| `text` | `str` | Новый текст |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить комментарий по comment_id
   └─ Если не найден → CommentNotFoundError
3. Проверить, что actor.id == comment.author_id
   └─ Если нет → CommentEditDeniedError
4. Проверить временное окно:
   (now() - comment.created_at) < 15 минут
   └─ Если окно истекло → CommentEditWindowExpiredError
5. Вызвать comment.edit(text)
   └─ Обновляет text, устанавливает edited_at = now()
6. Сохранить в БД
7. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `CommentNotFoundError` | Комментарий не найден |
| `CommentEditDeniedError` | Редактирует не автор |
| `CommentEditWindowExpiredError` | Прошло более 15 минут |

---

## Результат

`None` — успешное выполнение.

---

## Бизнес-правила

- Редактировать комментарий может только **автор** — не менеджер, не admin
- Окно редактирования: **15 минут** — зафиксировано в PRD
- После редактирования сохраняется `edited_at` — клиент видит "(изменено)"
