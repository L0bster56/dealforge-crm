# UseCase: ListLeadComments — Список комментариев лида

## Что решает

Возвращает все комментарии к лиду в хронологическом порядке (от новых к старым). Отображается в разделе "Комментарии" карточки лида.

**Статус:** ❌ Не реализовано (планируется — Приоритет 2)

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Пользователь с доступом к лиду |
| **Роли** | Все роли (с ограничениями) |

---

## Входные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `lead_id` | `UUID` | ID лида |
| `page` | `int` | Страница |
| `size` | `int` | Размер страницы |

---

## Порядок действий

```
1. Загрузить и проверить доступ к лиду
2. Загрузить комментарии с пагинацией, отсортированные по created_at DESC
3. Вернуть PageResult[CommentViewDTO]
```

---

## Результат (`CommentViewDTO`)

| Поле | Тип |
|------|-----|
| `id` | `UUID` |
| `text` | `str` |
| `author_id` | `UUID` |
| `author_name` | `str` |
| `created_at` | `datetime` |
| `edited_at` | `datetime \| None` |
| `is_editable` | `bool` (в течение 15 мин после создания) |

---

## Бизнес-правила

- Удалённые комментарии не отображаются
- `is_editable` вычисляется на бэкенде: `author_id == actor.id AND (now() - created_at) < 15 min`
