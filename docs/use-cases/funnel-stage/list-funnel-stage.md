# UseCase: ListFunnelStage — Список этапов воронки

## Что решает

Возвращает все этапы указанной воронки в правильном порядке. Нормализует порядок этапов через сервис сортировки — исправляет возможные несоответствия поля `order` в БД. Используется для отображения Kanban-колонок.

**Файл:** `backend/src/backend/application/funnel/use_cases/list_funnel_stage.py`

**Статус:** ✅ Реализовано

## Входные данные

Воронка передаётся как атрибут use case (`self.funnel`). Дополнительных параметров нет.

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить все этапы воронки из БД
   uow.stages.get_funnel_stages(self.funnel.id)
3. Нормализовать порядок через FunnelStageOrderingServices.normalize(stages)
   └─ Алгоритм:
      a) Отсортировать этапы по текущему полю order
      b) Пройти по отсортированному списку
      c) Если order этапа ≠ его индексу → обновить order = index
   (нормализация — idempotent операция)
4. Вернуть отсортированный список FunnelStage
```

---

## Возможные ошибки

Нет специфических ошибок — пустой список возвращается корректно.

---

## Результат

`list[FunnelStage]` — этапы воронки в порядке от `order = 0` до последнего.

---

## Бизнес-правила

- Нормализация **не сохраняет** изменённые `order` в БД — только для ответа клиенту (исправление происходит при следующей операции insert/move/delete)
- Этапы возвращаются **все** (включая архивированные `is_archived = True`)
