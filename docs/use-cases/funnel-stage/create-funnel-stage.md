# UseCase: CreateFunnelStage — Создать этап воронки

## Что решает

Добавляет новый этап (стадию) в воронку продаж. Этап вставляется в указанную позицию, а все остальные этапы автоматически сдвигаются для поддержания корректного порядка. Этап определяет вероятность выигрыша сделки и отображается определённым цветом на Kanban-доске.

**Файл:** `backend/src/backend/application/funnel/use_cases/create_funnel_stage.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Менеджер или выше |
| **Роли** | `sales_manager`, `director`, `admin` |

---

## Входные данные (`CreateFunnelStageCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | `str` | Название этапа |
| `win_probability` | `int` | Вероятность выигрыша 0–100 (%) |
| `hex` | `str` | Цвет этапа в HEX формате (`#RRGGBB`) |
| `position` | `int \| None` | Позиция вставки (0-based). Если None — добавляется в конец |

Воронка передаётся как атрибут use case (`self.funnel`).

---

## Порядок действий

```
1. Проверить права актора через CanCreateFunnelPolicy
   │  Правило: роль должна быть sales_manager и выше
   └─ Если нет прав → ошибка PermissionError (до открытия UoW)

2. Открыть Unit of Work

3. Загрузить все существующие этапы воронки из БД
   uow.stages.get_funnel_stages(self.funnel.id)

4. Создать новый этап через FunnelStage.create(...)
   └─ Валидация:
      - Name: не пустое, max 255 символов
      - Probability: целое число от 0 до 100
      - HexCode: строка формата #RRGGBB (ровно 7 символов)

5. Определить позицию вставки:
   - Если cmd.position задана → использовать её
   - Иначе → len(stages) (добавить в конец)

6. Вставить этап в список через FunnelStageOrderingServices.insert(stages, stage, position)
   └─ Алгоритм:
      a) Отсортировать существующие этапы по полю order
      b) Зажать position в диапазон [0, len(stages)]
      c) Вставить новый этап на указанную позицию
      d) Переназначить order = index для всех этапов в списке

7. Сохранить все этапы (включая обновлённые) через uow.stages.save_all(updated_stages)

8. Зафиксировать транзакцию (commit)

9. Вернуть CreateFunnelStageResult(stage_id=stage.id)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `PermissionError` | Роль актора — `consultant` |
| `ValueError` (VO Name) | Название пустое или > 255 символов |
| `ValueError` (VO Probability) | Вероятность выходит за диапазон 0–100 |
| `ValueError` (VO HexCode) | Цвет не соответствует формату `#RRGGBB` |

---

## Результат (`CreateFunnelStageResult`)

| Поле | Тип | Описание |
|------|-----|----------|
| `stage_id` | `UUID` | ID созданного этапа |

---

## Бизнес-правила

- При вставке в середину списка **все последующие этапы сдвигаются** — `order` пересчитывается для всего списка
- Позиция **зажимается** в диапазон `[0, len(stages)]` — нельзя вставить на отрицательную или слишком большую позицию
- Новый этап по умолчанию имеет тип `kind = intermediate` (начальный/финальный типы устанавливаются отдельно при необходимости)
