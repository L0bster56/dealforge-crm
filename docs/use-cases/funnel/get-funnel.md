# UseCase: GetFunnel — Получить воронку по ID

## Что решает

Загружает воронку продаж по её UUID. Используется как вспомогательный use case перед операциями над воронкой (обновление, удаление, работа со стадиями).

**Файл:** `backend/src/backend/application/funnel/use_cases/get_funnel.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Любой авторизованный пользователь |
| **Роли** | Все роли |

---

## Входные данные (`GetFunnelCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `funnel_id` | `UUID` | Идентификатор воронки |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Загрузить воронку из БД по funnel_id
3. Если воронка не найдена → ошибка FunnelNotFoundError
4. Вернуть доменную сущность Funnel
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `FunnelNotFoundError` | Воронка с указанным ID не существует |

---

## Результат

Доменная сущность `Funnel`:

| Поле | Тип |
|------|-----|
| `id` | `UUID` |
| `name` | `Name` |
| `is_deleted` | `bool` |
| `created_at` | `datetime` |
| `updated_at` | `datetime` |

---

## Бизнес-правила

- Удалённые воронки (`is_deleted = True`) также возвращаются — фильтрация по `is_deleted` не производится на уровне use case
- Используется в роутере как dependency: получить воронку → передать в следующий use case (update, delete, stage operations)
