# UseCase: CreateFunnel — Создать воронку продаж

## Что решает

Создаёт новую воронку продаж с указанным именем. Воронка — это именованный контейнер для этапов (стадий), по которым движется лид от первого контакта до сделки или отказа.

**Файл:** `backend/src/backend/application/funnel/use_cases/create_funnel.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Менеджер или выше |
| **Роли** | `sales_manager`, `director`, `admin` |

---

## Входные данные (`CreateFunnelCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | `str` | Название воронки |

---

## Порядок действий

```
1. Проверить права актора через CanCreateFunnelPolicy
   │  Правило: роль должна быть sales_manager и выше
   └─ Если нет прав → ошибка PermissionError (до открытия UoW)

2. Открыть Unit of Work

3. Создать доменную сущность Funnel через Funnel.create(name=cmd.name)
   └─ Валидация через Value Object Name (не пустое, max 255 символов)
   └─ Генерируется новый UUID
   └─ is_deleted = False

4. Сохранить воронку в БД через uow.funnels.create_funnel(funnel)

5. Зафиксировать транзакцию (commit)

6. Вернуть CreateFunnelResult(funnel_id=funnel.id)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `PermissionError` | Роль актора — `consultant` |
| `ValueError` (VO) | Название воронки пустое или превышает 255 символов |

---

## Результат (`CreateFunnelResult`)

| Поле | Тип | Описание |
|------|-----|----------|
| `funnel_id` | `UUID` | ID созданной воронки |

---

## Бизнес-правила

- Воронка создаётся **без этапов** — этапы добавляются отдельно через `CreateFunnelStage`
- Уникальность названия не проверяется — в системе может быть несколько воронок с одинаковым именем
- `is_deleted = False` при создании — воронка сразу активна и видима
