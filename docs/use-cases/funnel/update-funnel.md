# UseCase: UpdateFunnel — Переименовать воронку

## Что решает

Обновляет название существующей воронки продаж. В текущей версии воронка имеет только одно изменяемое поле — `name`.

**Файл:** `backend/src/backend/application/funnel/use_cases/update_funnel.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Менеджер или выше |
| **Роли** | `sales_manager`, `director`, `admin` |

---

## Входные данные (`UpdateFunnelCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | `str` | Новое название воронки |

Воронка передаётся как атрибут use case (`self.funnel`) — загружается заранее через `GetFunnel`.

---

## Порядок действий

```
1. Проверить права актора через CanUpdateFunnelPolicy
   │  Правило: роль должна быть sales_manager и выше
   └─ Если нет прав → ошибка PermissionError (до открытия UoW)

2. Открыть Unit of Work

3. Вызвать funnel.change_name(cmd.name)
   └─ Валидация через Value Object Name (не пустое, max 255 символов)

4. Сохранить воронку в БД через uow.funnels.update_funnel(self.funnel)

5. Зафиксировать транзакцию (commit)
```

---

## Возможные ошибки

| Ошибка | Условие |
|--------|---------|
| `PermissionError` | Роль актора — `consultant` |
| `ValueError` (VO) | Новое название пустое или превышает 255 символов |

---

## Результат

`None` — успешное выполнение без возвращаемого значения.

---

## Бизнес-правила

- Воронка должна быть загружена **до** вызова use case (через `GetFunnel`) — это ответственность роутера
- Уникальность нового названия **не проверяется**
