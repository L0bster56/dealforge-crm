# UseCase: ListFunnel — Список воронок

## Что решает

Возвращает постраничный список воронок продаж. Поддерживает пагинацию и фильтрацию. Используется на главной странице для отображения всех воронок компании.

**Файл:** `backend/src/backend/application/funnel/use_cases/list_funnel.py`

**Статус:** ✅ Реализовано

---

## Участники

| Поле | Значение |
|------|----------|
| **Actor** | Любой авторизованный пользователь |
| **Роли** | Все роли |

---

## Входные данные (`ListFunnelCommand`)

| Поле | Тип | Описание |
|------|-----|----------|
| `page` | `int` | Номер страницы (начиная с 1) |
| `size` | `int` | Размер страницы |
| `include_deleted` | `bool` | Включать ли удалённые воронки |

---

## Порядок действий

```
1. Открыть Unit of Work
2. Передать параметры в репозиторий uow.funnels.get_funnels(cmd)
   (репозиторий применяет фильтрацию, сортировку, пагинацию)
3. Вернуть PageResult[Funnel]
```

---

## Возможные ошибки

Нет специфических ошибок — пустой список возвращается корректно.

---

## Результат (`PageResult[Funnel]`)

| Поле | Тип | Описание |
|------|-----|----------|
| `items` | `list[Funnel]` | Список воронок на текущей странице |
| `page` | `int` | Текущая страница |
| `size` | `int` | Размер страницы |
| `total_items` | `int` | Общее количество воронок |

---

## Бизнес-правила

- По умолчанию удалённые воронки (`is_deleted = True`) **не включаются** в список
- Фильтрация и сортировка делегируются в репозиторий — use case остаётся тонким
